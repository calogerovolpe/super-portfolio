Savoir-faire — Démonstrations web

HTML &
CSS.

Des briques concrètes montrées avec leur code : structure sémantique, CSS moderne, JavaScript vanilla, Tailwind, formulaire de don, menu responsive et grille redimensionnable — et l'environnement WordPress, Elementor, Divi, VS Code, Cline et GitHub.

Le principe

01 — Transparence

Méthode

Montrer le code,
pas seulement le résultat.

Un portfolio de communication web doit prouver qu'il sait construire, pas seulement composer. Cette page montre les briques de base : une structure HTML propre, un CSS lisible, du JavaScript vanilla et l'équivalent en Tailwind.

Chaque démonstration est interactive et accessible : elle s'ouvre au clavier, se teste et se compare. Le site reste statique, sans framework ni build ; le CSS maison reste la référence.

JavaScript vanilla

04
Parce qu'un site statique n'a pas besoin de framework pour être interactif : quelques fonctions suffisent et le poids reste minimal.
Un clic change l'attribut aria-expanded et l'attribut hidden du panneau. Le focus reste visible et le contenu est lisible au clavier.
bouton.addEventListener('click', function () {
  var ouvert =
    bouton.getAttribute('aria-expanded') === 'true';
  bouton.setAttribute('aria-expanded',
    ouvert ? 'false' : 'true');
  panneau.hidden = ouvert;
});
