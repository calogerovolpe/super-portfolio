Démonstrations — HTML · CSS · Tailwind

La base,
en pratique.

Cette page rassemblera des démonstrations interactives : HTML sémantique, CSS moderne et composants Tailwind. Elle sera construite au jalon 5, avec des exemples à ouvrir, manipuler et comparer.

Au programme

Jalon 5

01

HTML sémantique

Structure, landmarks, formulaires, tableaux et accessibilité. Des exemples commentés, pas des extraits abstraits.

02

CSS moderne

Variables, grid, flexbox, transitions et responsive. Des composants qui se manipulent directement dans la page.

03

Tailwind

Utilitaires, composants et comparaison avec le CSS maison. Les mêmes blocs, deux approches, un seul objectif.

Pourquoi cette page ?

Transparence

Méthode

Montrer le code,
pas seulement le résultat.

Un portfolio de communication web doit prouver qu'il sait construire, pas seulement composer. Cette page montrera les briques de base : une structure HTML propre, un CSS lisible, et l'équivalent en Tailwind.

Les démonstrations seront interactives et accessibles : chaque exemple pourra être ouvert, testé au clavier et comparé à sa version Tailwind.
