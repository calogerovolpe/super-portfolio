# Project brief

## Objectif

Créer un super-portfolio public, en ligne, qui démontre les compétences de
Volpe Calogero en design graphique et en communication web, ainsi que sa capacité
à piloter une IA (Cline sur VS Code) pour produire un site sur mesure.

## Périmètre

- Un site statique complet, publié sur GitHub Pages et accessible publiquement.
- Une page par projet, avec un court texte descriptif et les documents consultables.
- Une page « HTML & CSS » de démonstration (bases HTML/CSS + exemples Tailwind).
- Une identité visuelle cohérente : jaune, noir, blanc ; carrés et rectangles
  exclusivement.
- Une page d'accueil mémorable, interactive et légère.

## Projets couverts

1. **Bakery Bliss Café** — étude et conception, charte graphique, prototype Figma,
   site web, animation vidéo, datavisualisation, affiche, dépliant.
2. **Business plan Sosse** — business plan réalisé sur InDesign, entreprise fictive
   dotée d'une identité visuelle.
3. **Casa Urpi** — charge graphique.
4. **L'îlot Câlins** — charte graphique et mascotte ; projet réel, diffusion autorisée.
5. **Flat design** — illustration SVG (page dédiée).

## Critères de réussite

- Le site est accessible publiquement et chaque page répond.
- L'identité (trois couleurs, formes carrées) est respectée sur toutes les pages.
- Les images et documents s'ouvrent et se ferment (lightbox).
- Le code est lisible, sans framework lourd, et démontre une réelle maîtrise du JS.
- Chaque modification est poussée et visible en ligne immédiatement.
