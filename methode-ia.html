Méthode — ce que je fais à 100 %

Le design est
100 % humain.
Le code,
je l'assiste.

L'identité visuelle, les couleurs, les formes, les dessins, les logos, les polices et les retouches photo sont créés par moi, avec des outils dédiés. L'IA n'intervient que sur le code (hors HTML/CSS) et la traduction — et je la vérifie.

Ce que je fais moi-même, à 100 %

01 — 100 % humain

L'humain est irremplaçable : pour la créativité, pour la sensibilité et pour la compréhension sociale. Une machine ne ressent pas un public, ne choisit pas une nuance, ne décide pas ce qui va toucher.

Tout ce qui relève de la communication visuelle est produit par moi, avec les outils dédiés : le choix des couleurs, le choix des formes (uniquement carrées et rectangulaires), les dessins graphiques, le choix des polices, la création des logos et des éléments graphiques.

Les retouches photo — Lightroom, Photoshop — sont également faites par moi-même. Et tous les projets de la page Projets ont été réalisés à 100 % par moi : rien n'a été fait par l'IA.

Ce que je délègue à l'IA

02 — Une petite partie

Seuls deux domaines passent par l'IA : le code et la traduction. Pour le code, il s'agit du JavaScript, du Python et des scripts de contrôle. Pour la traduction, il s'agit du français vers le néerlandais : mon niveau B2 me permet de relire et de corriger, pas de rédiger seul un site complet.

Sauf le HTML et le CSS (et Tailwind) : je les écris moi-même. L'IA ne sert alors qu'à trois choses : vérifier une autre solution, corriger une syntaxe quand ça bloque, et exécuter des tâches répétitives pour gagner du temps.

Ce que j'assiste

  • JavaScript et Python
  • Traduction FR → NL

Le HTML, le CSS et Tailwind restent écrits par moi.

Ma procédure

03 — En cinq étapes

Chaque livrable suit le même cycle. Les cartes ci-dessous décrivent ce que je fais concrètement, pas ce que l'outil promet.

01

Définir la demande

Je pose le contexte, le public, le livrable attendu, les contraintes (trois couleurs, formes carrées, accessibilité) et un exemple de ce que je veux. Une demande floue produit un résultat flou.

Preuve : brief écrit
02

Faire produire l'IA

Je découpe le travail : une page, un composant, un script à la fois. Je fournis les fichiers existants et je demande une sortie complète, pas un extrait à recopier.

Preuve : cahier des charges
03

Vérifier

Je lis la sortie ligne à ligne, je compare avec la demande et je cherche ce qui ne tient pas : un lien faux, une couleur en trop, un arrondi interdit, une phrase mal traduite.

Preuve : notes de contrôle
04

Corriger et itérer

Je reformule la demande, je simplifie ou je retire. Je corrige moi-même ce que je sais corriger et je fais reprendre le reste. Un résultat n'est jamais accepté du premier coup.

Preuve : historique Git
05

Tester et valider

J'ouvre le site dans le navigateur, je teste desktop et mobile, le clavier, le thème clair, les liens et la console. Je ne publie que ce qui fonctionne.

Preuve : captures et tests

Exemples concrets

04 — Cas concrets

Deux cas où l'IA m'assiste sur du HTML/CSS ou des répétitions, trois où elle produit du code ou de la traduction que je vérifie.

Corriger du CSS

style.css

J'écris mon CSS à la main. Quand une règle bloque, je montre le bloc à l'IA et je lui demande de repérer l'erreur de syntaxe — pas de réécrire le design.

:root {
  --jaune #FFD500;   /* il manque les deux-points */
}
.cta {
  display grid;      /* il manque les deux-points */
}

/* Correction proposée */
--jaune: #FFD500;
display: grid;

Contrôle : je compare la correction à mon intention, je relis la règle et je valide. Le choix du design reste le mien.

Répéter une ligne

15 pages

Plutôt que de copier-coller la même balise dans quinze pages à la main, je demande à l'IA d'ajouter la ligne identique partout. Je garde le contrôle du contenu ; l'IA fait la répétition.

« Ajoute cette ligne dans les 15 pages HTML,
juste avant </head> :

<link rel="stylesheet" href="assets/css/style.css"> »

Contrôle : je vérifie dans le diff Git que la ligne est identique et au bon endroit dans chaque page.

JavaScript vanilla

nav.js

L'IA écrit les interactions (thème, retour en haut, lightbox). Je lis le code ligne à ligne, je vérifie la syntaxe avec node --check et je teste chaque comportement dans le navigateur.

var bouton = document.querySelector('.back-to-top');
bouton.addEventListener('click', function () {
  window.scrollTo({ top: 0, behavior: 'smooth' });
});

Contrôle : le bouton apparaît après 400 px, le clic remonte, la touche Échap ferme la lightbox, aucune erreur dans la console.

Traductions FR → NL

B2

L'IA traduit les textes du site. Je relis chaque phrase avec mon niveau B2, je vérifie le vocabulaire métier et je corrige ce qui sonne faux.

FR : « Projets fictifs, sauf L'îlot Câlins. »
NL : « Fictieve projecten, behalve L'îlot Câlins. »

Contrôle : relecture mot à mot, cohérence des termes (huisstijl, oplevering), vérification des accents et des majuscules.

Python

PyMuPDF

L'IA m'aide à écrire les scripts qui extraient le texte des PDF et qui vérifient les pages. Je lis le résultat, je compare avec le document et je corrige les chemins ou les encodages.

import fitz
doc = fitz.open("charte.pdf")
print(doc[0].get_text())

Contrôle : le texte extrait correspond au PDF, les 14 pages sont trouvées, le script s'arrête proprement en cas d'erreur.

Comment je vérifie

05 — Avec mes moyens

Je ne prétends pas tout comprendre au même niveau qu'un développeur. Je vérifie ce qui est vérifiable, avec des outils simples et des contrôles répétables.

  • Syntaxe : node --check sur chaque fichier JavaScript.
  • HTML : un script Python contrôle les balises, les identifiants, les liens locaux et les images.
  • Rendu : captures desktop et mobile, contrôle du responsive et du thème clair.
  • Accessibilité : navigation au clavier, lien d'évitement, alt, focus visible.
  • Langue : relecture néerlandaise phrase par phrase, avec dictionnaire et bon sens.
  • Versionnage : chaque modification est relue dans le diff Git avant le commit.

La règle

Si je ne peux pas expliquer ce qu'un bloc fait, je ne le publie pas. Je simplifie, je reformule la demande ou je retire la fonctionnalité.

Ce que cela démontre

06 — Professionnalisme

La création reste humaine ; l'IA n'est qu'un outil d'appoint pour le code et la traduction. Savoir l'utiliser, c'est savoir formuler une demande, reconnaître une erreur, arbitrer et livrer un résultat fiable.

Cette démarche montre trois choses : je maîtrise la création visuelle de bout en bout, je connais mes limites techniques, et je ne publie rien que je n'ai pas vérifié.

En une phrase

L'IA me permet de produire au niveau attendu ; la vérification garantit que le résultat est le mien.
