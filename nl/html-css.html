Het principe

01 — Transparantie

Methode

Toon de code,
niet alleen het resultaat.

Een webcommunicatieportfolio moet bewijzen dat het kan bouwen, niet alleen componeren. Deze pagina toont de basisbouwstenen: een propere HTML-structuur, leesbare CSS, vanilla JavaScript, het Tailwind-equivalent en schrijven in Markdown.

Elke demo is interactief en toegankelijk: hij opent met het toetsenbord, laat zich testen en vergelijken. De site blijft statisch, zonder framework of build; de eigen CSS blijft de referentie.

Vanilla JavaScript

04
Omdat een statische site geen framework nodig heeft om interactief te zijn: een paar functies volstaan en het gewicht blijft minimaal.
Een klik wijzigt het attribuut aria-expanded en het attribuut hidden van het paneel. De focus blijft zichtbaar en de inhoud blijft leesbaar met het toetsenbord.
bouton.addEventListener('click', function () {
  var ouvert =
    bouton.getAttribute('aria-expanded') === 'true';
  bouton.setAttribute('aria-expanded',
    ouvert ? 'false' : 'true');
  panneau.hidden = ouvert;
});
